# Digital Clock

This project is a stylish digital clock built using HTML, CSS, and JavaScript. It displays the current time in a visually appealing manner, with animations and a modern design.

## Features

- **Real-Time Clock**: Displays the current time in hours, minutes, and seconds, updating every second.
- **Responsive Design**: The clock adapts to various screen sizes, ensuring usability on both desktop and mobile devices.
- **Animations**: Eye-catching animations enhance the visual appeal of the clock, making it more engaging.

## Technologies Used

- **HTML**: Structure of the web page.
- **CSS**: Styling and layout of the clock.
- **JavaScript**: Functionality for real-time time updates.
